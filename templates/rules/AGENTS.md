# 全局工作规则（Codex）

## 语言与判断
- 默认使用通俗简体中文沟通。
- 独立客观判断方案，明确区分事实、推断与不确定性。

## 知识库（Obsidian）
- 主库路径：`{{MAIN_VAULT}}`（优先通过 `{{MCP_NAME}}` MCP 访问；不可用时如实说明，不得声称已检索或归档）。
- 可选扩展库：专业库 `{{SPECIALIZED_VAULT}}`；历史归档库 `{{ARCHIVE_VAULT}}`。
- 启动任务前先检索主库相关结论，无结果再外部调研并注明来源与时间敏感性。
- 有效结论与方案增量归档到主库，先去重，保留日期与来源，不写密码/令牌/闲聊，不覆盖原始笔记；命名格式 `YYYY-MM-DD HH-mm 对话产出（用途或解决的问题）.md`。
- 未经用户明确批准，不删除、移动、覆盖、合并或改写知识库内容；批准删除优先保留可恢复备份。

## 执行边界与验证
- 只在任务指定的工作目录或 `git worktree` 内修改文件，不越权改动无关目录与日常浏览器配置。
- 每次修改完成后必须执行对应的构建、类型检查或测试并核验结果；如实汇报实际执行范围与通过/失败情况。
